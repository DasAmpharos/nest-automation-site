Privacy policy

Last updated October 23, 2026

nest-automation is a personal project used by a single household to control its own Nest thermostats. It is not a commercial service and has no users outside that household.

Data accessed

With the household's authorization, the app uses the Google Smart Device Management API to read and change the household's own Nest thermostats. This includes indoor temperature, humidity, heating and cooling status, setpoints, and thermostat mode.

The app also records whether household members' phones are on the home Wi-Fi network, and receives arrive/leave events that household members choose to send from their own phones. It also records comfort feedback ("too warm", "too cold", "fine") that household members submit.

How data is used

Data is used only to choose thermostat setpoints and to measure how well the app saves energy. Summaries of thermostat state, the weather forecast and comfort feedback are sent to the Anthropic API to help plan setpoints. Weather forecasts are fetched from Open-Meteo, and no household data is sent to Open-Meteo.

Storage and sharing

Data is stored on a computer inside the home. It is not sold, not used for advertising, and not shared with anyone except the services named above, which the app needs in order to work.

Retention and deletion

The household can delete the stored data at any time. Google access can be revoked at any time from the Google Account permissions page (myaccount.google.com/permissions) or the Nest partner connections page (nestservices.google.com/partnerconnections).

Google API Services User Data Policy

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions about this policy can be raised by opening an issue on this site's GitHub repository.
